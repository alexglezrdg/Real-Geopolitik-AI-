# ARREGLOS APLICADOS - 27 Enero 2025

## Problema Reportado
1. **Texto visible en imágenes**: El prompt de DALL-E aparecía renderizado en las imágenes ("Create a cinematic...")
2. **Noticias repetidas**: Múltiples posts sobre el mismo tema (Cuba/Rusia bloqueo naval)
3. **Falta de diversidad**: Pocas fuentes RSS, poca variedad de noticias

## Soluciones Implementadas

### 1. Prompt DALL-E Mejorado
**Archivo**: `src/openai_image.ts`

**Cambio**: Prompt mucho más enfático sobre NO incluir texto
```typescript
// ANTES:
"Create a clean, editorial, cinematic image relevant to the news topic.
NO text, NO words, NO letters..."

// AHORA:
"IMPORTANT: Generate ONLY a photograph or illustration. DO NOT include ANY text, writing, letters, words, or captions of any kind in the image.
You are creating a background image for news content. The text will be added separately later.
ZERO text elements (no English, Spanish, or any language text)..."
```

**Resultado**: Instrucciones más claras para DALL-E 3 para prevenir texto visible

### 2. Sistema de Deduplicación Mejorado
**Archivo**: `src/dedupe_store.ts`

**Cambios principales**:

#### a) Topic Cooldown Reducido
- **Antes**: 72 horas
- **Ahora**: 48 horas
- Previene repetir el mismo tema más rápidamente

#### b) Topic Hash con Extracción de Entidades
Nueva función `extractKeyEntities()` que identifica:
- Países/regiones geopolíticas (Cuba, Rusia, USA, etc.)
- Acciones clave (bloqueo, sanciones, guerra, etc.)
- Normaliza variaciones (rusia/russia → russia, EEUU/USA → usa)

**Ejemplo**:
```
"Rusia en alarma por bloqueo naval a Cuba"
→ Entities: [blockade, cuba, russia]

"EEUU considera bloqueo naval a Cuba según Kremlin"  
→ Entities: [blockade, cuba, russia, usa]

Ambos se detectan como MISMO TEMA porque comparten las entidades core.
```

#### c) Normalización de USA
USA se excluye del topic hash cuando es solo contexto (mencionado como objetivo) pero se incluye cuando es el actor principal (título empieza con "EEUU").

**Resultado**: Noticias similares como las 5 variantes de Cuba/Rusia se detectan como duplicados.
