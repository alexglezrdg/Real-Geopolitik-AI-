ROLLBACK STEPS (if something breaks)
================================================================================

1. Stop bot:
   pkill -f "npm run dev"

2. Restore database backup:
   cp data/bot.sqlite.backup data/bot.sqlite

3. Revert dedupe_store.ts changes (restore from git):
   git checkout src/dedupe_store.ts

4. Restart:
   npm run dev -- --live

================================================================================
TROUBLESHOOTING
================================================================================

Q: "no such column: topic_hash" error
A: Run migration: sqlite3 data/bot.sqlite "ALTER TABLE dedupe_entries ADD COLUMN topic_hash TEXT;"

Q: Tests show "isDuplicate not found"
A: Make sure you're awaiting checkDuplicate(): const dup = await checkDuplicate(...)

Q: Topic hash not matching for related stories
A: Check if stopwords are filtering out key terms. Run debugTopicHash() to inspect.

Q: Too many false positives (stories blocked incorrectly)
A: Increase Simhash Hamming threshold or adjust stopwords list

Q: Token usage still high
A: Check LLM_SCORE_THRESHOLD setting (default 85)
   Lower it to use more templates: export LLM_SCORE_THRESHOLD=75

Q: Lock timeout errors
A: Increase lock timeout in src/process_lock.ts:
   Change acquireLock(5000) to acquireLock(10000)
