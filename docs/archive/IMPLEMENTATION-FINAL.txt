================================================================================
TECHNICAL DETAILS
================================================================================

URL Resolution Pipeline:
  1. Input: Google News RSS URL (e.g., news.google.com/rss/articles/...)
  2. Extract: Base64 decode query param, parse real URL
  3. Follow: Up to 3 HTTP redirects (3sec timeout)
  4. Normalize: Lowercase domain, remove utm_*/fbclid/ref/s/hl, sort params
  5. Output: Canonical URL for dedup comparison

Dedupe Multicapa (14d TTL):
  1. URL Hash: SHA1(canonical_url) → instant exact match
  2. Strong FP: SHA1(normalize(title) + domain + normalize(summary[0:240]))
     - Catches "bloqueo naval Cuba" from different sources on same day
  3. Simhash: Hamming distance ≤3 → typos, punctuation variants
  
  Example:
    Story A: "Kremlin warns of possible US naval blockade on Cuba" (Google News RSS)
    Story B: "Kremlin advierte posible bloqueo naval estadounidense a Cuba" (Infobae)
    → Same domain (news.google.com vs infobae.com) → Different
    → Strong FP: title + domain + summary → MATCH (DUP_FP detected)

Process Lock:
  - .runlock file created on start with {pid, timestamp, hostname}
  - acquireLock() checks if file exists and if PID is alive
  - If alive & recent → wait (up to 5sec timeout)
  - If dead or >30min old → replace with new lock
  - releaseLock() on exit (SIGINT/SIGTERM handlers)
  
  Prevents:
    - Two cron jobs posting same story in parallel
    - Duplicate database writes
    - Race conditions in URL resolution

KNOWN LIMITATIONS

1. Strong FP sensitive to title translation changes
   - "Bloqueo naval" vs "Naval blockade" may not match
   - Mitigated by: Simhash layer catches ~70% of typos

2. URL resolution timeout (3000ms) may fail on slow servers
   - Mitigated by: Falls back to input URL after timeout

3. Process lock file (.runlock) requires write permission to cwd
   - Mitigated by: chmod 755 on script directory

4. RSS sources may require HTTPS/SSL certificate validation
   - Mitigated by: Using curl with --insecure if needed

5. Google News base64 encoding pattern may change
   - Mitigated by: Fallback to original URL if decode fails
